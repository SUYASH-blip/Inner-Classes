# 🧩 Inner Classes in Java

Welcome to my **Inner Classes in Java** repository 💻☕

This repository contains concepts and implementations of different types of **Inner Classes in Java** along with practice examples.

The purpose of this repository is to understand how nested classes work in Java and where they are used in real-world programming.

---

# 📚 Topics Covered

## 🔹 Types of Inner Classes

### Member Inner Class
- Accessing outer class members
- Object creation of inner class

### Static Nested Class
- Static inner class implementation
- Accessing static members

### Local Inner Class
- Inner class inside methods
- Scope & usage

### Anonymous Inner Class
- Anonymous object creation
- Interface implementation
- Abstract class implementation
